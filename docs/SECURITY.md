# Security Policy

## Reporting a Vulnerability
We take the security of the VORTCOIN Layer-1 network very seriously. If you discover a critical security vulnerability or an exploit vector within the core engine, **please do not open a public issue.**

Instead, report the issue immediately by contacting our core infrastructure team at **security@vortcoin.org** (or your designated private channel). Provide a detailed proof of concept (PoC) so we can patch the network securely before the public release.
